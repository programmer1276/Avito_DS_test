# Локальная модель E5

В полном ZIP включены веса `intfloat/multilingual-e5-small` и файлы токенизатора. После git clone их подготавливает `python setup_assets.py`; скачивается та же зафиксированная версия с проверкой SHA-256.

- Источник: https://huggingface.co/intfloat/multilingual-e5-small
- Зафиксированная версия: `614241f622f53c4eeff9890bdc4f31cfecc418b3`.
- Лицензия: MIT, согласно карточке авторов; исходная карточка сохранена в `MODEL_CARD.md`.
- Архитектура: 12 слоёв, вектор 384 компоненты.
- SHA-256 `model.safetensors`: `1a55775f53449dac10a2bcbc312469fac40b96d53198c407081a831f81c98477`.
- Хеши и размеры всех необходимых файлов: `model_manifest.json`.

Копии обычные, без символических ссылок на кэш разработчика. ONNX-варианты не нужны и не включены.

При работе используется локальный каталог `models/e5-small` и `local_files_only=True`; сетевой доступ для инференса не нужен. Для запросов нужен префикс `query: `, для объявлений — `passage: `. Векторы нормализуются по L2.

В данном решении запросы ограничены 64 токенами. Заголовок объявления ограничен 64 токенами; расширенное представление содержит заголовок, первые 200 символов параметров и первые 500 символов описания, до 128 токенов.
