Распакуйте сюда три исходных файла из dataset.zip:

- train.parquet
- benchmark_items.parquet
- benchmark_queries.parquet

Данные задания не включены в репозиторий. Можно хранить их в другой папке
и передавать её через --data-dir. В ноутбуке путь задаётся DATA_DIR или
переменной окружения AVITO_DATA_DIR.
